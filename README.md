# Onda

Personal Android radio player: watches Synology-Drive-synced M3U
playlists (source of truth: pyradio's stations.csv in the dotfiles
repo), renders them with real groups, browses radio-browser.info, and
rides Media3 for background playback and Android Auto.

Kotlin + Jetpack Compose + Media3. Sideloaded via Obtainium from this
repo's releases. See `docs/spec.md` and `CLAUDE.md`.
