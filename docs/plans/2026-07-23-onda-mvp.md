# Onda MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete Onda MVP — watched-playlist radio player with radio-browser discovery, pending-favorites round-trip, and Android Auto — per `docs/superpowers/specs/2026-07-23-onda-design.md`.

**Architecture:** Two Gradle modules: `:core` (pure Kotlin/JVM — M3U parsing, radio-browser client, pending CSV, media-id scheme) and `:app` (Android — Compose UI, Media3 `MediaLibraryService`, SAF folder access). Manual constructor DI from `OndaApp`.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), Media3 (exoplayer + session + HLS), kotlinx.serialization, OkHttp (API only), Coil 3, kotlin.test + MockWebServer.

## Global Constraints

- Package id: `dev.basiliskus.onda`. `:core` code in `dev.basiliskus.onda.core.*`.
- `:core` MUST NOT import anything from `android.*` or `androidx.*`.
- Streams play through Media3 `DefaultHttpDataSource` only (HttpURLConnection-based; tolerates shoutcast `ICY 200 OK`). OkHttp is for radio-browser API calls only — never for streams.
- Discovery/favorites always use the radio-browser `url` field, never `url_resolved` (preserves self-healing redirects).
- Every radio-browser station list request includes `order=votes&reverse=true&hidebroken=true`.
- Theme: Catppuccin Latte (light) / Frappé (dark) as named semantic colors. No ad-hoc hex outside `Catppuccin.kt`. Dynamic color off.
- minSdk 29, compileSdk/targetSdk 35. Versions in the catalog are tested floors — bump each to latest stable at execution time; if a bump breaks compilation, stay on the floor and note it in the PR.
- Git: per CLAUDE.md, never commit to main. Execute this plan on branch `feature/mvp`; commit after every task's final step; one PR for the milestone at the end (large PR is acceptable for the MVP per CLAUDE.md Git workflow).
- Environment prerequisites (verify in Task 1): JDK 17+, Android SDK (`ANDROID_HOME` or `local.properties`), a connected device or emulator for manual-verify steps. On an emulator, create the synced folder with `adb push ~/Sync/Radio /sdcard/Radio`.
- pyradio stations.csv column order (the pending.csv base schema): `name,url,encoding,icon,profile,buffering,force-http,volume,referer,player`. Comment lines start with `#`.

```kotlin
package dev.basiliskus.onda.core.model

import java.security.MessageDigest

object MediaIds {
    const val ROOT = "root"

    private fun hash(s: String): String =
        MessageDigest.getInstance("SHA-1").digest(s.toByteArray())
            .joinToString("") { "%02x".format(it) }.take(12)

    fun playlist(name: String) = "playlist|$name"
    fun group(playlist: String, group: String) = "group|$playlist|${hash(group)}"
    fun station(s: Station) = "station|${hash("${s.playlist}|${s.group}|${s.url}")}"
    fun rb(uuid: String) = "rb|$uuid"

    fun stationIndex(playlists: List<Playlist>): Map<String, Station> =
        playlists.flatMap { it.stations }.associateBy { station(it) }

    sealed interface Parsed {
        data object Root : Parsed
        data class PlaylistNode(val playlist: String) : Parsed
        data class GroupNode(val playlist: String, val groupHash: String) : Parsed
        data class StationNode(val key: String) : Parsed
        data class RbNode(val uuid: String) : Parsed
    }

    fun parse(id: String): Parsed? {
        if (id == ROOT) return Parsed.Root
        val parts = id.split('|')
        return when {
            parts.size == 2 && parts[0] == "playlist" -> Parsed.PlaylistNode(parts[1])
            parts.size == 3 && parts[0] == "group" -> Parsed.GroupNode(parts[1], parts[2])
            parts.size == 2 && parts[0] == "station" -> Parsed.StationNode(parts[1])
            parts.size == 2 && parts[0] == "rb" -> Parsed.RbNode(parts[1])
            else -> null
        }
    }

    fun groupMatches(parsed: Parsed.GroupNode, playlist: String, group: String) =
        parsed.playlist == playlist && parsed.groupHash == hash(group)
}
```

Note: group segments are hashed so arbitrary characters in group titles (pipes, slashes) can never break id structure; `groupMatches` is how the Auto tree finds the group a `GroupNode` refers to.

`core/src/main/kotlin/dev/basiliskus/onda/core/m3u/M3uParser.kt`:
```kotlin
package dev.basiliskus.onda.core.m3u

import dev.basiliskus.onda.core.model.Group
import dev.basiliskus.onda.core.model.Playlist
import dev.basiliskus.onda.core.model.Station

object M3uParser {
    private val attr = Regex("""([\w-]+)="([^"]*)"""")

    fun parsePlaylist(fileBaseName: String, text: String): Playlist {
        val lines = text.removePrefix("﻿").lines().map { it.trim() }
        val stations = mutableListOf<Station>()
        var pending: Triple<String, String?, String?>? = null // name, group, logo
        for (line in lines) {
            when {
                line.isEmpty() -> {}
                line.startsWith("#EXTINF:") -> {
                    pending = parseExtinf(line)
                }
                line.startsWith("#") -> {} // other directives ignored
                else -> {
                    val p = pending
                    if (p != null && (line.startsWith("http://") || line.startsWith("https://"))) {
                        stations += Station(
                            name = p.first,
                            url = line,
                            group = p.second ?: "Ungrouped",
                            playlist = fileBaseName,
                            logo = p.third,
                        )
                    }
                    pending = null
                }
            }
        }
        val groups = stations.groupBy { it.group }.map { (title, ss) -> Group(title, ss) }
        val order = stations.map { it.group }.distinct()
        return Playlist(fileBaseName, groups.sortedBy { order.indexOf(it.title) })
    }

    private fun parseExtinf(line: String): Triple<String, String?, String?>? {
        val afterColon = line.substringAfter("#EXTINF:")
        val name = afterColon.substringAfter(',', "").trim()
        if (name.isEmpty()) return null
        val attrsPart = afterColon.substringBefore(',')
        val attrs = attr.findAll(attrsPart).associate { it.groupValues[1] to it.groupValues[2] }
        return Triple(name, attrs["group-title"], attrs["tvg-logo"])
    }
}
```

Note the subtlety: the display name is everything after the FIRST comma of the attribute section — but attribute values are quoted and precede the comma, while the name itself may contain commas. The real exporter emits `#EXTINF:-1 group-title="X",Name`; `substringBefore(',')` on the attr part is safe because your exporter's attribute values never contain commas, and the name is recovered as `substringAfter(',')` from the part after attributes. If test 3 (comma in name) fails with this simple split, use this stricter variant: find the end of the last quoted attribute, then take everything after the next comma as the name.

```kotlin
package dev.basiliskus.onda.core.m3u

object IndirectionParser {
    private val plsFile = Regex("""^File\d+\s*=\s*(\S+)""", RegexOption.IGNORE_CASE)

    fun looksLikeIndirection(url: String): Boolean {
        val path = url.substringBefore('?').substringBefore('#').lowercase()
        return path.endsWith(".pls") || path.endsWith(".m3u")
    }

    fun firstStreamUrl(body: String): String? {
        for (raw in body.lineSequence()) {
            val line = raw.trim()
            plsFile.find(line)?.let { return it.groupValues[1] }
            if (line.startsWith("http://") || line.startsWith("https://")) return line
        }
        return null
    }
}
```

```kotlin
package dev.basiliskus.onda.core.favorites

data class PendingStation(
    val name: String,
    val url: String,
    val icon: String = "",
    val stationuuid: String = "",
    val tags: String = "",
    val country: String = "",
    val votes: Int = 0,
)

object PendingCsv {
    const val HEADER =
        "# name,url,encoding,icon,profile,buffering,force-http,volume,referer,player,stationuuid,tags,country,votes"

    fun serialize(stations: List<PendingStation>): String =
        buildString {
            appendLine(HEADER)
            stations.forEach { s ->
                val fields = listOf(
                    s.name, s.url, "", s.icon, "", "", "", "", "", "",
                    s.stationuuid, s.tags, s.country, s.votes.toString(),
                )
                appendLine(fields.joinToString(",") { quote(it) })
            }
        }

    fun parse(text: String): List<PendingStation> =
        text.lineSequence()
            .map { it.trim() }
            .filter { it.isNotEmpty() && !it.startsWith("#") }
            .mapNotNull { line ->
                val f = splitCsv(line)
                if (f.size != 14) return@mapNotNull null
                PendingStation(
                    name = f[0], url = f[1], icon = f[3],
                    stationuuid = f[10], tags = f[11], country = f[12],
                    votes = f[13].toIntOrNull() ?: 0,
                )
            }
            .toList()

    fun toggle(existing: List<PendingStation>, s: PendingStation): List<PendingStation> =
        if (existing.any { it.url == s.url }) existing.filterNot { it.url == s.url }
        else existing + s

    private fun quote(field: String): String =
        if (field.any { it == ',' || it == '"' || it == '\n' })
            "\"${field.replace("\"", "\"\"")}\""
        else field

    private fun splitCsv(line: String): List<String> {
        val out = mutableListOf<String>()
        val cur = StringBuilder()
        var inQuotes = false
        var i = 0
        while (i < line.length) {
            val c = line[i]
            when {
                inQuotes && c == '"' && i + 1 < line.length && line[i + 1] == '"' -> { cur.append('"'); i++ }
                c == '"' -> inQuotes = !inQuotes
                c == ',' && !inQuotes -> { out += cur.toString(); cur.clear() }
                else -> cur.append(c)
            }
            i++
        }
        out += cur.toString()
        return out
    }
}
```

```kotlin
package dev.basiliskus.onda.core.radiobrowser

import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.Json
import okhttp3.HttpUrl.Companion.toHttpUrl
import okhttp3.OkHttpClient
import okhttp3.Request
import java.io.IOException

@Serializable
data class RbStation(
    val stationuuid: String,
    val name: String,
    val url: String,
    val favicon: String = "",
    val tags: String = "",
    val country: String = "",
    val countrycode: String = "",
    val codec: String = "",
    val bitrate: Int = 0,
    val votes: Int = 0,
)

@Serializable data class RbTag(val name: String, val stationcount: Int)
@Serializable data class RbCountry(val name: String, val iso_3166_1: String, val stationcount: Int)

data class StationFilter(
    val name: String? = null,
    val tag: String? = null,
    val countrycode: String? = null,
)

class RadioBrowserClient(
    private val http: OkHttpClient,
    private val mirrors: List<String> = DEFAULT_MIRRORS,
) {
    companion object {
        val DEFAULT_MIRRORS = listOf(
            "https://de1.api.radio-browser.info",
            "https://nl1.api.radio-browser.info",
            "https://at1.api.radio-browser.info",
        )
        const val USER_AGENT = "Onda/0.1 (github.com/basiliskus/onda)"
    }

    private val json = Json { ignoreUnknownKeys = true }
    @Volatile private var preferredMirror = 0

    suspend fun searchStations(filter: StationFilter, offset: Int = 0, limit: Int = 30): List<RbStation> =
        get("/json/stations/search", buildMap {
            filter.name?.let { put("name", it) }
            filter.tag?.let { put("tag", it); put("tagExact", "true") }
            filter.countrycode?.let { put("countrycode", it) }
            put("order", "votes"); put("reverse", "true"); put("hidebroken", "true")
            put("offset", offset.toString()); put("limit", limit.toString())
        })

    suspend fun topTags(limit: Int = 100): List<RbTag> =
        get("/json/tags", mapOf("order" to "stationcount", "reverse" to "true", "limit" to limit.toString(), "hidebroken" to "true"))

    suspend fun countries(): List<RbCountry> =
        get("/json/countries", mapOf("order" to "name", "hidebroken" to "true"))

    private suspend inline fun <reified T> get(path: String, params: Map<String, String>): T =
        withContext(Dispatchers.IO) {
            var lastError: IOException? = null
            val start = preferredMirror
            for (i in mirrors.indices) {
                val idx = (start + i) % mirrors.size
                val url = mirrors[idx].toHttpUrl().newBuilder().encodedPath(path).apply {
                    params.forEach { (k, v) -> addQueryParameter(k, v) }
                }.build()
                try {
                    http.newCall(Request.Builder().url(url).header("User-Agent", USER_AGENT).build())
                        .execute().use { resp ->
                            if (!resp.isSuccessful) throw IOException("HTTP ${resp.code} from ${mirrors[idx]}")
                            val body = resp.body!!.string()
                            preferredMirror = idx
                            return@withContext json.decodeFromString<T>(body)
                        }
                } catch (e: IOException) { lastError = e }
            }
            throw lastError ?: IOException("no mirrors configured")
        }
}
```

```kotlin
package dev.basiliskus.onda.sync

import android.content.Context
import android.content.Intent
import android.database.ContentObserver
import android.net.Uri
import android.provider.DocumentsContract
import androidx.documentfile.provider.DocumentFile
import androidx.lifecycle.DefaultLifecycleObserver
import androidx.lifecycle.LifecycleOwner
import androidx.lifecycle.ProcessLifecycleOwner
import dev.basiliskus.onda.core.m3u.M3uParser
import dev.basiliskus.onda.core.model.Playlist
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.launch

sealed interface PlaylistsState {
    data object NeedsFolder : PlaylistsState
    data object Loading : PlaylistsState
    data class Ready(val playlists: List<Playlist>) : PlaylistsState
}

class PlaylistRepository(
    private val context: Context,
    private val prefs: FolderPrefs,
    private val scope: CoroutineScope,
) {
    private val knownOrder = listOf("stations", "nts", "fip", "bbc", "public-radio", "radio-garden")
    private val _state = MutableStateFlow<PlaylistsState>(
        if (prefs.treeUri == null) PlaylistsState.NeedsFolder else PlaylistsState.Loading
    )
    val state: StateFlow<PlaylistsState> = _state
    private var lastHash = 0

    init {
        ProcessLifecycleOwner.get().lifecycle.addObserver(object : DefaultLifecycleObserver {
            override fun onStart(owner: LifecycleOwner) = rescan()
        })
        registerObserver()
    }

    fun setFolder(uri: Uri) {
        context.contentResolver.takePersistableUriPermission(
            uri, Intent.FLAG_GRANT_READ_URI_PERMISSION or Intent.FLAG_GRANT_WRITE_URI_PERMISSION
        )
        prefs.treeUri = uri
        registerObserver()
        rescan()
    }

    fun rescan() {
        val tree = prefs.treeUri ?: run { _state.value = PlaylistsState.NeedsFolder; return }
        scope.launch(Dispatchers.IO) {
            val dir = DocumentFile.fromTreeUri(context, tree)
            if (dir == null || !dir.canRead()) {
                _state.value = PlaylistsState.NeedsFolder; return@launch
            }
            val texts = dir.listFiles()
                .filter { it.name?.endsWith(".m3u") == true }
                .mapNotNull { f ->
                    val name = f.name!!.removeSuffix(".m3u")
                    context.contentResolver.openInputStream(f.uri)?.use { ins ->
                        name to ins.reader().readText()
                    }
                }
            val hash = texts.hashCode()
            if (hash == lastHash && _state.value is PlaylistsState.Ready) return@launch
            lastHash = hash
            val playlists = texts.map { (name, text) -> M3uParser.parsePlaylist(name, text) }
                .sortedWith(compareBy({ knownOrder.indexOf(it.name).let { i -> if (i == -1) knownOrder.size else i } }, { it.name }))
            _state.value = PlaylistsState.Ready(playlists)
        }
    }

    fun readPendingText(): String? {
        val tree = prefs.treeUri ?: return null
        val dir = DocumentFile.fromTreeUri(context, tree) ?: return null
        val file = dir.findFile("pending.csv") ?: return null
        return context.contentResolver.openInputStream(file.uri)?.use { it.reader().readText() }
    }

    fun writePendingText(text: String) {
        val tree = prefs.treeUri ?: return
        val dir = DocumentFile.fromTreeUri(context, tree) ?: return
        val tmp = dir.findFile("pending.csv.tmp")?.also { it.delete() }
            .let { dir.createFile("text/csv", "pending.csv.tmp")!! }
        context.contentResolver.openOutputStream(tmp.uri, "wt")!!.use { it.write(text.toByteArray()) }
        dir.findFile("pending.csv")?.delete()
        DocumentsContract.renameDocument(context.contentResolver, tmp.uri, "pending.csv")
    }

    private fun registerObserver() {
        val tree = prefs.treeUri ?: return
        val childrenUri = DocumentsContract.buildChildDocumentsUriUsingTree(
            tree, DocumentsContract.getTreeDocumentId(tree)
        )
        context.contentResolver.registerContentObserver(childrenUri, true,
            object : ContentObserver(null) {
                override fun onChange(selfChange: Boolean) = rescan()
            })
    }
}
```

```kotlin
import androidx.media3.datasource.ResolvingDataSource
import dev.basiliskus.onda.core.m3u.IndirectionParser
import dev.basiliskus.onda.core.radiobrowser.RadioBrowserClient
import java.net.HttpURLConnection
import java.net.URL

/** Play-time resolution of .pls/.m3u indirection. Runs on Media3's loading thread (blocking IO is expected). */
class IndirectionResolver : ResolvingDataSource.Resolver {
    override fun resolveDataSpec(dataSpec: DataSpec): DataSpec {
        var uri = dataSpec.uri
        var hops = 0
        while (IndirectionParser.looksLikeIndirection(uri.toString()) && hops < 3) {
            val body = fetch(uri.toString()) ?: break
            val next = IndirectionParser.firstStreamUrl(body) ?: break
            uri = Uri.parse(next)
            hops++
        }
        return if (uri == dataSpec.uri) dataSpec else dataSpec.withUri(uri)
    }

    private fun fetch(url: String): String? = try {
        val conn = URL(url).openConnection() as HttpURLConnection
        conn.connectTimeout = 10_000
        conn.readTimeout = 10_000
        conn.instanceFollowRedirects = true
        conn.setRequestProperty("User-Agent", RadioBrowserClient.USER_AGENT)
        conn.inputStream.use { String(it.readNBytes(64 * 1024)) }
    } catch (_: Exception) { null }
}
```

```kotlin
class PlaybackService : MediaLibraryService() {
    private var session: MediaLibrarySession? = null
    private var lastRetriedMediaId: String? = null

    private val stationIndex: Map<String, Station>
        get() = ((application as OndaApp).graph.playlistRepository.state.value as? PlaylistsState.Ready)
            ?.let { MediaIds.stationIndex(it.playlists) } ?: emptyMap()

    override fun onCreate() {
        super.onCreate()
        // DefaultHttpDataSource (HttpURLConnection) is REQUIRED here: it tolerates
        // shoutcast v1 "ICY 200 OK" status lines that OkHttp rejects. Do not swap.
        val httpFactory = DefaultHttpDataSource.Factory()
            .setUserAgent(RadioBrowserClient.USER_AGENT)
            .setAllowCrossProtocolRedirects(true)
            .setConnectTimeoutMs(15_000)
            .setReadTimeoutMs(15_000)
        val dataSourceFactory = ResolvingDataSource.Factory(
            DefaultDataSource.Factory(this, httpFactory),
            IndirectionResolver(),
        )
        val player = ExoPlayer.Builder(this)
            .setMediaSourceFactory(DefaultMediaSourceFactory(dataSourceFactory))
            .setAudioAttributes(
                AudioAttributes.Builder().setUsage(C.USAGE_MEDIA).setContentType(C.AUDIO_CONTENT_TYPE_MUSIC).build(),
                /* handleAudioFocus = */ true,
            )
            .setHandleAudioBecomingNoisy(true)
            .setWakeMode(C.WAKE_MODE_NETWORK)
            .build()
        player.addListener(object : Player.Listener {
            override fun onMediaItemTransition(item: MediaItem?, reason: Int) { lastRetriedMediaId = null }
            override fun onPlayerError(error: PlaybackException) {
                val id = player.currentMediaItem?.mediaId ?: return
                if (lastRetriedMediaId != id) {
                    lastRetriedMediaId = id
                    player.prepare(); player.play()
                } // else: stay idle; controllers observe the error state
            }
        })
        session = MediaLibrarySession.Builder(this, player, LibraryCallback()).build()
    }

    override fun onGetSession(controllerInfo: MediaSession.ControllerInfo) = session

    override fun onDestroy() {
        session?.run { player.release(); release() }
        session = null
        super.onDestroy()
    }

    inner class LibraryCallback : MediaLibrarySession.Callback {
        override fun onAddMediaItems(
            mediaSession: MediaSession,
            controller: MediaSession.ControllerInfo,
            mediaItems: MutableList<MediaItem>,
        ): ListenableFuture<MutableList<MediaItem>> {
            val resolved = mediaItems.map { item ->
                stationIndex[item.mediaId]?.let { s -> playableItem(item.mediaId, s.name, s.url, s.logo) }
                    ?: item.requestMetadata.mediaUri?.let { uri ->
                        item.buildUpon().setUri(uri).build()
                    } ?: item
            }.toMutableList()
            return Futures.immediateFuture(resolved)
        }
        // Task 14 adds onGetLibraryRoot / onGetChildren here.
    }

    companion object {
        fun playableItem(mediaId: String, title: String, url: String, artworkUrl: String?): MediaItem =
            MediaItem.Builder()
                .setMediaId(mediaId)
                .setUri(url)
                .setRequestMetadata(
                    MediaItem.RequestMetadata.Builder().setMediaUri(android.net.Uri.parse(url)).build()
                )
                .setMediaMetadata(
                    MediaMetadata.Builder()
                        .setTitle(title)
                        .setStation(title)
                        .setArtworkUri(artworkUrl?.let(android.net.Uri::parse))
                        .setIsPlayable(true).setIsBrowsable(false)
                        .setMediaType(MediaMetadata.MEDIA_TYPE_RADIO_STATION)
                        .build()
                )
                .build()
    }
}
```

```kotlin
package dev.basiliskus.onda.playback

import android.content.ComponentName
import android.content.Context
import androidx.media3.common.MediaItem
import androidx.media3.common.MediaMetadata

import dev.basiliskus.onda.core.radiobrowser.RbStation
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.guava.await
import kotlinx.coroutines.launch

data class NowPlaying(
    val mediaId: String,
    val stationName: String,
    val streamTitle: String?,
    val artworkUrl: String?,
    val playingUrl: String,
    val isPlaying: Boolean,
    val isBuffering: Boolean,
    val error: String?,
)

class PlayerConnection(private val context: Context, private val scope: CoroutineScope) {
    private val _nowPlaying = MutableStateFlow<NowPlaying?>(null)
    val nowPlaying: StateFlow<NowPlaying?> = _nowPlaying
    private var controller: MediaController? = null

    init {
        scope.launch(Dispatchers.Main) {
            val token = SessionToken(context, ComponentName(context, PlaybackService::class.java))
            controller = MediaController.Builder(context, token).buildAsync().await().also { c ->
                c.addListener(object : Player.Listener {
                    override fun onEvents(player: Player, events: Player.Events) = publish(c)
                })
                publish(c)
            }
        }
    }

    private fun publish(c: MediaController) {
        val item = c.currentMediaItem ?: run { _nowPlaying.value = null; return }
        val meta: MediaMetadata = c.mediaMetadata
        val requested = item.requestMetadata.mediaUri?.toString() ?: ""
        _nowPlaying.value = NowPlaying(
            mediaId = item.mediaId,
            stationName = (meta.station ?: meta.title ?: "Unknown station").toString(),
            streamTitle = meta.title?.toString()?.takeIf { it != (meta.station ?: "").toString() },
            artworkUrl = meta.artworkUri?.toString(),
            playingUrl = requested,
            isPlaying = c.isPlaying,
            isBuffering = c.playbackState == Player.STATE_BUFFERING,
            error = c.playerError?.let { humanize(it) },
        )
    }

    private fun humanize(e: PlaybackException) = "Station unreachable"

    private fun play(item: MediaItem) {
        val c = controller ?: return
        c.setMediaItem(item); c.prepare(); c.play()
    }

    fun playStation(s: Station) =
        play(PlaybackService.playableItem(MediaIds.station(s), s.name, s.url, s.logo))

    fun playRb(s: RbStation) =
        play(PlaybackService.playableItem(MediaIds.rb(s.stationuuid), s.name, s.url, s.favicon.ifBlank { null }))

    fun toggle() {
        val c = controller ?: return
        if (c.isPlaying) c.stop() else { c.prepare(); c.play() }
    }

    fun stop() { controller?.stop() }
}
```

```kotlin
package dev.basiliskus.onda.ui.discover

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dev.basiliskus.onda.core.radiobrowser.*
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.launch
import java.io.IOException

const val PAGE_SIZE = 30

data class StationListState(
    val stations: List<RbStation> = emptyList(),
    val loading: Boolean = false,
    val endReached: Boolean = false,
    val error: String? = null,
)

class DiscoverViewModel(private val client: RadioBrowserClient) : ViewModel() {
    val tags = MutableStateFlow<List<RbTag>?>(null)
    val countries = MutableStateFlow<List<RbCountry>?>(null)
    val browseError = MutableStateFlow<String?>(null)

    private val _list = MutableStateFlow(StationListState())
    val list: StateFlow<StationListState> = _list
    private var filter = StationFilter()

    fun loadBrowseLists() {
        if (tags.value == null) viewModelScope.launch {
            try { tags.value = client.topTags() } catch (e: IOException) { browseError.value = "radio-browser unreachable" }
        }
        if (countries.value == null) viewModelScope.launch {
            try { countries.value = client.countries() } catch (e: IOException) { browseError.value = "radio-browser unreachable" }
        }
    }

    fun openList(kind: String, value: String) {
        filter = when (kind) {
            "tag" -> StationFilter(tag = value)
            "country" -> StationFilter(countrycode = value)
            "search" -> StationFilter(name = value)
            else -> StationFilter() // top: no filter, votes ordering does the work
        }
        _list.value = StationListState(loading = true)
        loadMore(reset = true)
    }

    fun loadMore(reset: Boolean = false) {
        val cur = _list.value
        if (!reset && (cur.loading || cur.endReached)) return
        viewModelScope.launch {
            _list.value = cur.copy(loading = true, error = null)
            try {
                val offset = if (reset) 0 else cur.stations.size
                val page = client.searchStations(filter, offset = offset, limit = PAGE_SIZE)
                _list.value = StationListState(
                    stations = (if (reset) emptyList() else cur.stations) + page,
                    endReached = page.size < PAGE_SIZE,
                )
            } catch (e: IOException) {
                _list.value = cur.copy(loading = false, error = "radio-browser unreachable")
            }
        }
    }
}
```

```kotlin
package dev.basiliskus.onda.sync

import dev.basiliskus.onda.core.favorites.PendingCsv
import dev.basiliskus.onda.core.favorites.PendingStation
import dev.basiliskus.onda.core.radiobrowser.RbStation
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.launch
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock

class FavoritesRepository(
    private val playlists: PlaylistRepository,
    private val scope: CoroutineScope,
) {
    private val _pendingUrls = MutableStateFlow<Set<String>>(emptySet())
    val pendingUrls: StateFlow<Set<String>> = _pendingUrls
    private val mutex = Mutex()

    init { refresh() }

    fun refresh() {
        scope.launch(Dispatchers.IO) {
            mutex.withLock {
                val current = playlists.readPendingText()?.let(PendingCsv::parse) ?: emptyList()
                _pendingUrls.value = current.map { it.url }.toSet()
            }
        }
    }

    fun toggle(s: RbStation) {
        scope.launch(Dispatchers.IO) {
            mutex.withLock {
                val current = playlists.readPendingText()?.let(PendingCsv::parse) ?: emptyList()
                val updated = PendingCsv.toggle(current, PendingStation(
                    name = s.name, url = s.url, icon = s.favicon,
                    stationuuid = s.stationuuid, tags = s.tags, country = s.country, votes = s.votes,
                ))
                playlists.writePendingText(PendingCsv.serialize(updated))
                _pendingUrls.value = updated.map { it.url }.toSet()
            }
        }
    }
}
```

```kotlin
override fun onGetLibraryRoot(
    session: MediaLibrarySession, browser: MediaSession.ControllerInfo, params: LibraryParams?,
): ListenableFuture<LibraryResult<MediaItem>> =
    Futures.immediateFuture(LibraryResult.ofItem(browsableItem(MediaIds.ROOT, "Onda"), params))

override fun onGetChildren(
    session: MediaLibrarySession, browser: MediaSession.ControllerInfo,
    parentId: String, page: Int, pageSize: Int, params: LibraryParams?,
): ListenableFuture<LibraryResult<ImmutableList<MediaItem>>> {
    val playlists = ((application as OndaApp).graph.playlistRepository.state.value as? PlaylistsState.Ready)
        ?.playlists ?: emptyList()
    val children: List<MediaItem> = when (val node = MediaIds.parse(parentId)) {
        is MediaIds.Parsed.Root ->
            playlists.map { browsableItem(MediaIds.playlist(it.name), it.name) }
        is MediaIds.Parsed.PlaylistNode ->
            playlists.firstOrNull { it.name == node.playlist }?.groups
                ?.map { g -> browsableItem(MediaIds.group(node.playlist, g.title), g.title) } ?: emptyList()
        is MediaIds.Parsed.GroupNode ->
            playlists.firstOrNull { it.name == node.playlist }?.groups
                ?.firstOrNull { MediaIds.groupMatches(node, node.playlist, it.title) }?.stations
                ?.map { s -> playableItem(MediaIds.station(s), s.name, s.url, s.logo) } ?: emptyList()
        else -> emptyList()
    }
    return Futures.immediateFuture(LibraryResult.ofItemList(ImmutableList.copyOf(children), params))
}

private fun browsableItem(id: String, title: String): MediaItem =
    MediaItem.Builder().setMediaId(id).setMediaMetadata(
        MediaMetadata.Builder().setTitle(title)
            .setIsBrowsable(true).setIsPlayable(false)
            .setMediaType(MediaMetadata.MEDIA_TYPE_FOLDER_MIXED).build()
    ).build()
```
